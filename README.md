# Andy's Math Notes

Personal mathematics notes covering undergraduate-level topics in Calculus and Linear Algebra.

## Overview

| Folder | Subject |
|--------|---------|
| [Calculus](Calculus/) | Calculus (limits, derivatives, integrals, series) |
| [Fundamentals](Fundamentals/) | Mathematical fundamentals |
| [linear algebra](linear%20algebra/) | Linear Algebra (vector spaces, matrices, linear transformations, eigenvalues) |

## Calculus Notes Structure

The calculus notes are written in Markdown with LaTeX math rendering.

- **Chapter 1 — The Concepts of Integral Calculus**
  - Area as a set function (axioms of area)
  - Intervals and ordinate sets
  - Partitions and step functions
  - Integration of step functions
  - Properties of the integral
  - Integrability of bounded monotonic functions
  - Upper and lower integrals
  - Integration of polynomials

- **Chapter 2 — Some Applications of Integration**
  - Area between two graphs
  - Worked examples (circular disk, similarity transformations)
  - Trigonometric functions and their integrals

## Format

- Notes are written in **Markdown** with embedded **LaTeX** formulas.
- Both English and Chinese versions are maintained where applicable.
- Definitions, theorems, and proofs are presented in a structured format.

## Usage

Browse the folders to find notes on specific topics. The main calculus notes are in `Calculus/Calculus-English version.md`.
