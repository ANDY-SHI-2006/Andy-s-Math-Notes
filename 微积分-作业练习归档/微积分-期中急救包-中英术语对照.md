## 二、Ch 7 —— 泰勒展开 Taylor Expansion

| 英文 | 中文 | 含义/公式 |
|------|------|-----------|
| **Taylor polynomial** | 泰勒多项式 | $T_n(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!}(x-a)^k$ |
| **Taylor series** | 泰勒级数 | 把泰勒多项式写到 $n\to\infty$ |
| **centered at** | 中心在 | 展开点 $a$，如 "centered at $x=0$" 就是在 0 处展开 |
| **Maclaurin series** | 麦克劳林级数 | 在 $a=0$ 处的泰勒级数 |
| **remainder** | 余项/误差 | $R_n(x) = f(x) - T_n(x)$ |
| **error term** | 误差项 | 同上 |
| **big-O notation** | 大O记号 | $f(x) = O(g(x))$ 表示 $|f(x)| \leq C|g(x)|$ |
| **little-o notation** | 小o记号 | $f(x) = o(g(x))$ 表示 $\lim \frac{f(x)}{g(x)} = 0$ |

**必背泰勒级数（在 $x=0$ 处）**：

| 函数 | 泰勒级数 | 收敛半径 |
|------|----------|----------|
| $e^x$ | $\sum_{n=0}^{\infty} \frac{x^n}{n!}$ | $\infty$ |
| $\sin x$ | $\sum_{n=0}^{\infty} \frac{(-1)^n x^{2n+1}}{(2n+1)!}$ | $\infty$ |
| $\cos x$ | $\sum_{n=0}^{\infty} \frac{(-1)^n x^{2n}}{(2n)!}$ | $\infty$ |
| $\frac{1}{1-x}$ | $\sum_{n=0}^{\infty} x^n$（当 $\|x\|<1$） | $1$ |
| $\log(1+x)$ | $\sum_{n=1}^{\infty} \frac{(-1)^{n+1}x^n}{n}$ | $1$ |
| $\arctan x$ | $\sum_{n=0}^{\infty} \frac{(-1)^n x^{2n+1}}{2n+1}$ | $1$ |
| $(1+x)^\alpha$ | $\sum_{n=0}^{\infty} \binom{\alpha}{n} x^n$ | $1$ |

**核心操作**：
- 替换（substitution）：把 $x$ 换成 $-x$, $x^2$, $2x$ 等
- 求导/积分：对级数逐项求导或积分
- 加减：两个级数相加减

## 三、Ch 10 —— 数列与级数 Sequences and Series

| 英文 | 中文 | 含义 |
|------|------|------|
| **sequence** | 数列 | $a_1, a_2, a_3, \ldots$ |
| **series** | 级数 | $\sum_{n=1}^{\infty} a_n = a_1 + a_2 + \cdots$ |
| **partial sum** | 部分和 | $S_n = a_1 + a_2 + \cdots + a_n$ |
| **geometric series** | 几何级数 | $\sum ar^n$，当 $\|r\|<1$ 时收敛于 $\frac{a}{1-r}$ |
| **harmonic series** | 调和级数 | $\sum \frac{1}{n}$，**发散** |
| **p-series** | p-级数 | $\sum \frac{1}{n^p}$，$p>1$ 收敛，$p\leq 1$ 发散 |
| **alternating series** | 交错级数 | $\sum (-1)^n a_n$ |
| **telescoping series** | 裂项级数 | 中间项抵消，只剩首尾 |
| **improper integral** | 反常积分 | 积分区间无限或被积函数无界 |

**收敛判别法（必背！）**：

| 英文 | 中文 | 内容 | 结论 |
|------|------|------|------|
| **nth term test** | 通项判别法 | 若 $\lim a_n \neq 0$，则发散 | 只能判发散，不能判收敛 |
| **comparison test** | 比较判别法 | $0 \leq a_n \leq b_n$，若 $\sum b_n$ 收敛则 $\sum a_n$ 收敛 | 大收则小收，小发则大发 |
| **limit comparison test** | 极限比较判别法 | $\lim \frac{a_n}{b_n} = c > 0$，则同敛散 | 找等价无穷小 |
| **ratio test** | 比值判别法 | $\lim \left|\frac{a_{n+1}}{a_n}\right| = L$ | $L<1$ 收敛，$L>1$ 发散，$L=1$ 不确定 |
| **root test** | 根值判别法 | $\lim \sqrt[n]{\|a_n\|} = L$ | 同上 |
| **integral test** | 积分判别法 | $f(n)=a_n$ 正、连续、递减，则 $\sum a_n$ 与 $\int f(x)dx$ 同敛散 | |
| **alternating series test** (Leibniz) | 莱布尼茨判别法 | $a_n > 0$ 递减且 $\to 0$，则交错级数收敛 | 判条件收敛 |
| **absolute convergence** | 绝对收敛 | $\sum \|a_n\|$ 收敛 $\Rightarrow$ $\sum a_n$ 收敛 | 绝对收敛 $\Rightarrow$ 收敛 |

## 四、Ch 11 —— 函数项级数 Sequences and Series of Functions

| 英文 | 中文 | 含义 |
|------|------|------|
| **pointwise convergence** | 点态收敛 | 对每个固定的 $x$，级数收敛 |
| **uniform convergence** | 一致收敛 | 整个区间上"一起"收敛，速度一致 |
| **power series** | 幂级数 | $\sum_{n=0}^{\infty} c_n (x-a)^n$ |
| **radius of convergence** | 收敛半径 | $r$，使得 $\|x-a\|<r$ 时收敛 |
| **interval of convergence** | 收敛区间 | $(a-r, a+r)$，可能包含端点 |
| **Weierstrass M-test** | M判别法 | 若 $\|f_n(x)\| \leq M_n$ 且 $\sum M_n$ 收敛，则一致收敛 |
| **term-by-term integration** | 逐项积分 | 一致收敛时可逐项积分 |
| **term-by-term differentiation** | 逐项求导 | 导函数级数一致收敛时可逐项求导 |

**收敛半径求法**：
- 比值法：$r = \lim_{n\to\infty} \left|\frac{c_n}{c_{n+1}}\right|$（如果极限存在）
- 根值法：$r = \frac{1}{\limsup \sqrt[n]{\|c_n\|}}$

**端点判断**：把 $x = a+r$ 和 $x = a-r$ 代入，单独判断级数收敛性。

## 五、Ch 13 —— 向量解析几何 Vector Geometry

| 英文 | 中文 | 含义/公式 |
|------|------|-----------|
| **vector** | 向量 | 有大小和方向的量，如 $\boldsymbol{v} = (v_1, v_2, v_3)$ |
| **scalar** | 标量 | 普通的数（无方向） |
| **component** | 分量 | 向量的各个坐标值 |
| **norm/length/magnitude** | 模/长度 | $\|\boldsymbol{v}\| = \sqrt{v_1^2 + v_2^2 + v_3^2}$ |
| **unit vector** | 单位向量 | 长度为 1 的向量 |
| **dot product / inner product / scalar product** | 点乘/内积/数量积 | $\boldsymbol{a} \cdot \boldsymbol{b} = a_1b_1 + a_2b_2 + a_3b_3 = \|\boldsymbol{a}\|\|\boldsymbol{b}\|\cos\theta$ |
| **cross product / vector product** | 叉乘/向量积 | $\boldsymbol{a} \times \boldsymbol{b}$，结果垂直于 $\boldsymbol{a}$ 和 $\boldsymbol{b}$ |
| **scalar triple product** | 混合积/标量三重积 | $[\boldsymbol{a},\boldsymbol{b},\boldsymbol{c}] = \boldsymbol{a} \cdot (\boldsymbol{b} \times \boldsymbol{c})$ |
| **orthogonal / perpendicular** | 正交/垂直 | $\boldsymbol{a} \cdot \boldsymbol{b} = 0$ |
| **parallel** | 平行 | $\boldsymbol{a} = k\boldsymbol{b}$（$k$ 为标量） |
| **linearly dependent** | 线性相关 | 存在不全为零的数使得线性组合为零 |
| **linearly independent** | 线性无关 | 只有当系数全为零时线性组合才为零 |

**直线（Line）**：
- **parametric equation**：$\boldsymbol{r}(t) = \boldsymbol{P} + t\boldsymbol{d}$，$\boldsymbol{P}$ 是直线上一点，$\boldsymbol{d}$ 是**方向向量（direction vector）**
- **symmetric equations**：$\frac{x-x_0}{a} = \frac{y-y_0}{b} = \frac{z-z_0}{c}$

**平面（Plane）**：
- **normal vector**（法向量）：垂直于平面的向量 $\boldsymbol{n}$
- **point-normal form**：$\boldsymbol{n} \cdot (\boldsymbol{r} - \boldsymbol{P}) = 0$
- **general form**：$Ax + By + Cz + D = 0$，其中 $(A,B,C)$ 是法向量
- **through three points**（过三点）：$\boldsymbol{r}(s,t) = \boldsymbol{P} + s(\boldsymbol{Q}-\boldsymbol{P}) + t(\boldsymbol{R}-\boldsymbol{P})$

**叉乘公式**：
$$\boldsymbol{a} \times \boldsymbol{b} = \begin{vmatrix} \boldsymbol{i} & \boldsymbol{j} & \boldsymbol{k} \\ a_1 & a_2 & a_3 \\ b_1 & b_2 & b_3 \end{vmatrix}$$

**混合积性质**：
- 循环对称：$\boldsymbol{a} \cdot (\boldsymbol{b} \times \boldsymbol{c}) = \boldsymbol{b} \cdot (\boldsymbol{c} \times \boldsymbol{a}) = \boldsymbol{c} \cdot (\boldsymbol{a} \times \boldsymbol{b})$
- 交换叉乘和点乘：$\boldsymbol{a} \cdot (\boldsymbol{b} \times \boldsymbol{c}) = (\boldsymbol{a} \times \boldsymbol{b}) \cdot \boldsymbol{c}$
- 几何意义：混合积的绝对值 = 三个向量张成的平行六面体的体积

## 六、Ch 14 —— 向量值函数微积分 Vector-Valued Functions

| 英文 | 中文 | 含义/公式 |
|------|------|-----------|
| **vector-valued function** | 向量值函数 | $\boldsymbol{r}(t) = (f(t), g(t), h(t))$ |
| **position vector** | 位置向量 | 描述点在空间中的位置 |
| **velocity** | 速度 | $\boldsymbol{v}(t) = \boldsymbol{r}'(t) = (f'(t), g'(t), h'(t))$ |
| **speed** | 速率 | $\|\boldsymbol{v}(t)\|$（速度的大小） |
| **acceleration** | 加速度 | $\boldsymbol{a}(t) = \boldsymbol{v}'(t) = \boldsymbol{r}''(t)$ |
| **tangent vector** | 切向量 | $\boldsymbol{r}'(t)$，指向运动方向 |
| **unit tangent vector** | 单位切向量 | $\boldsymbol{T}(t) = \frac{\boldsymbol{r}'(t)}{\|\boldsymbol{r}'(t)\|}$ |
| **arc length** | 弧长 | $L = \int_a^b \|\boldsymbol{r}'(t)\|\, dt$ |
| **curvature** | 曲率 | $\kappa = \frac{\|\boldsymbol{T}'(t)\|}{\|\boldsymbol{r}'(t)\|} = \frac{\|\boldsymbol{r}'(t) \times \boldsymbol{r}''(t)\|}{\|\boldsymbol{r}'(t)\|^3}$ |
| **angle of intersection** | 夹角 | 两条曲线在交点处切线之间的夹角 |

**弧长公式**：
$$L = \int_a^b \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2 + \left(\frac{dz}{dt}\right)^2}\, dt$$

**曲线夹角**：
- 求出两曲线在交点处的**切向量** $\boldsymbol{v}_1$ 和 $\boldsymbol{v}_2$
- $\cos\theta = \frac{|\boldsymbol{v}_1 \cdot \boldsymbol{v}_2|}{\|\boldsymbol{v}_1\|\|\boldsymbol{v}_2\|}$

## 七、题型速判表

| 看到题目关键词 | 对应方法 |
|---------------|----------|
| "converge or diverge" / "absolutely or conditionally" | 先判绝对收敛（比值/根值/比较），若不绝对收敛再用莱布尼茨判交错级数 |
| "radius of convergence" / "interval of convergence" | 比值法或根值法求 $r$，端点单独代入判断 |
| "Taylor series" / "centered at" | 套公式，或利用已知级数做替换/求导/积分 |
| "find the sum of the series" | 往几何级数、$-\log(1-x)$、$e^x$、三角函数级数上靠 |
| "arc length" | 套公式 $\int \|\boldsymbol{r}'(t)\| dt$ |
| "angle of intersection" | 求两曲线在交点处的切向量，用点乘公式 |
| "plane through... and perpendicular to..." | 法向量 = 两已知平面法向量的某种组合 |
| "scalar triple product" / "$\boldsymbol{u} \cdot (\boldsymbol{v} \times \boldsymbol{w})$" | 循环换序，注意正负号 |
