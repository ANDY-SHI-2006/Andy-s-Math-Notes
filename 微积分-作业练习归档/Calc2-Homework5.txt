Exercise 4. We call an equation involving at least one of the derivatives of an unknown function
a differential equation.
And a solution of a differential equation is a function that satisfies the
equation.
For example, the equation y′′ + y = 0 is a differential equation where y is treated as an
unknown function of x, and the function y = sin x is a solution of this equation.
(a). Verify that, for any constant c, the function f(x) = cex is a solution of the differential equation
f ′(x) = f(x).
(b). Given a fixed constant c, prove that there is one and only one function f that satisfies the
differential equation f ′(x) = f(x) as well as the condition f(0) = c. Here, the condition f(0) = c
is called an initial condition as it specifies the value of the solution at a particular point. And
we often call the problem of finding a solution to a differential equation that satisfies a given initial
condition an initial-value problem.
Hint: To prove existence, use part (a). To prove uniqueness, you may assume there is another
function g satisfying g′(x) = g(x) and g(0) = c. Then, you may prove that g(x)e−x = c (and hence
g(x) = cex) by showing that the derivative of h(x) = g(x)e−x is zero and h(0) = c.
