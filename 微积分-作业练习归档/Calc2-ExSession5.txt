Cross product and scalar triple product
Exercise 1. Prove the following identities of the cross product: For all vectors A, B, C in R3 and for all
real k we have:
(1). A × B = −(B × A) (skew symmetry),
(2). A × (B + C) = (A × B) + (A × C) (distributive law),
(3). k(A × B) = (kA) × B,
(4). A · (A × B) = 0 (orthogonality to A ),
(5). B · (A × B) = 0 (orthogonality to B ),
(6). ∥A × B∥2 = ∥A∥2∥B∥2 −(A · B)2 (Lagrange’s identity),
(7). A × B = O
if and only if A and B are linearly dependent.
Exercise 2. Let A = −i + 2k, B = 2i + j −k, C = i + 2j + 2k. Compute each of the following vectors
in terms of i, j, k :
(a). A × B;
(b). A × (C × A);
(c). (A × C) × B;
(d). B × C;
(e). (A × B) × C;
(f). (A + B) × (A −C);
(g). C × A;
(h). A × (B × C);
(i). (A × B) × (A × C).
Exercise 3. Given two linearly independent vectors A and B in R3. Let C = (B × A) −B.
(a). Prove that A is orthogonal to B + C.
(b). Prove that the angle θ between B and C satisfies 1
2π < θ < π.
(c). If ∥B∥= 1 and ∥B × A∥= 2, compute the length of C.
Exercise 4. Prove the following identities of the scalar triple product: For all vectors A, B, C in R3
(a). A × B · C = B × C · A = C × A · B (cyclic symmetry),
(b). A × B · C = A · B × C.
