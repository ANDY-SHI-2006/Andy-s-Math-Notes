# 1. Vector Spaces

## 1.1 Definitions

### 1.1.1 Preliminaries — Sets and Notation

- A **set** is a collection of objects; each object is an **element** of the set.
- $\mathbf{R}$ = set of all real numbers; $\mathbf{C}$ = set of all complex numbers.
- $\mathbf{R}^n$ = set of all $n$-tuples of real numbers.
- $u \in S$: "$u$ is an element of $S$" (or "$u$ lies in $S$").
- $S' \subset S$: $S'$ is a **subset** of $S$ (every element of $S'$ is in $S$).
  - If $S' \neq S$, then $S'$ is a **proper subset**.
- $S_1 \cap S_2$: **intersection** (elements in both).
- $S_1 \cup S_2$: **union** (elements in either).

### 1.1.2 Fields

Let $K \subset \mathbf{C}$. $K$ is a **field** if:

| Condition | Statement |
|-----------|-----------|
| **(a) Closure** | If $x, y \in K$, then $x + y \in K$ and $xy \in K$. |
| **(b) Inverses** | If $x \in K$, then $-x \in K$; if $x \neq 0$, then $x^{-1} \in K$. |
| **(c) Identity** | $0 \in K$ and $1 \in K$. |

**Examples:**
- $\mathbf{R}$ and $\mathbf{C}$ are fields.
- $\mathbf{Q}$ (rational numbers) is a field.
- $\mathbf{Z}$ (integers) is **not** a field (fails condition (b): e.g., $2^{-1} = \frac{1}{2} \notin \mathbf{Z}$).

> **Key idea:** A field is a set where addition, multiplication, and division by non-zero elements obey the ordinary rules of arithmetic.

**Subfield:** If $K \subset L$ and both are fields, $K$ is a **subfield** of $L$.
- $\mathbf{R}$ is a subfield of $\mathbf{C}$; $\mathbf{Q}$ is a subfield of $\mathbf{R}$.

Elements of a field are called **numbers** or **scalars**.

### 1.1.3 Vector Spaces

A **vector space** $V$ over a field $K$ is a set of objects that can be **added** and **multiplied by scalars** (elements of $K$), satisfying:

| Axiom | Statement |
|-------|-----------|
| **VS 1.** Associativity | $(u + v) + w = u + (v + w)$ |
| **VS 2.** Zero element | There exists $O \in V$ such that $O + u = u + O = u$ for all $u \in V$. |
| **VS 3.** Additive inverse | For each $u \in V$, there exists $-u \in V$ such that $u + (-u) = O$. |
| **VS 4.** Commutativity | $u + v = v + u$ |
| **VS 5.** Distributivity (scalar over vector sum) | $c(u + v) = cu + cv$ |
| **VS 6.** Distributivity (scalar sum over vector) | $(a + b)v = av + bv$ |
| **VS 7.** Compatibility | $(ab)v = a(bv)$ |
| **VS 8.** Identity | $1 \cdot u = u$ |

> **Note:** The zero element $O$ is uniquely determined by VS 2.

**Notation:**
- $0$ = number zero; $O$ = zero vector (zero element of $V$).
- $u - v$ means $u + (-v)$.

**Basic property:** $0v = O$ for any $v \in V$.

**Proof:** $0v + v = 0v + 1v = (0 + 1)v = 1v = v$. Adding $-v$ to both sides gives $0v = O$.

### 1.1.4 Example 1 — $K^n$

Let $V = K^n$ = set of $n$-tuples of elements of $K$.

For $A = (a_1, \dots, a_n)$ and $B = (b_1, \dots, b_n)$ in $K^n$:

$$
A + B = (a_1 + b_1, \dots, a_n + b_n)
$$

For $c \in K$:

$$
cA = (ca_1, \dots, ca_n)
$$

The zero element is $O = (0, \dots, 0)$.

All axioms VS 1–VS 8 are satisfied.

- $\mathbf{C}^n$ is a vector space over $\mathbf{C}$.
- $\mathbf{Q}^n$ is a vector space over $\mathbf{Q}$.
- $\mathbf{R}^n$ is **not** a vector space over $\mathbf{C}$.

> **Convention:** When we write $K^n$, it is always understood as a vector space over $K$. Elements of $K^n$ (and of any vector space) are called **vectors**.

### 1.1.5 Subspaces

Let $V$ be a vector space and $W \subset V$. $W$ is a **subspace** of $V$ if:

| Condition | Statement |
|-----------|-----------|
| **(i)** Closure under addition | If $v, w \in W$, then $v + w \in W$. |
| **(ii)** Closure under scalar multiplication | If $v \in W$ and $c \in K$, then $cv \in W$. |
| **(iii)** Contains zero | $O \in W$. |

Then $W$ itself is a vector space (axioms VS 1–VS 8 hold in $W$ because they hold in $V$).

**Example 2:** Let $V = K^n$ and let $W$ be the set of vectors whose last coordinate is $0$. Then $W$ is a subspace of $V$, identifiable with $K^{n-1}$.

### 1.1.6 Linear Combinations

Let $v_1, \dots, v_n \in V$ and $x_1, \dots, x_n \in K$. An expression of the form:

$$
x_1 v_1 + \cdots + x_n v_n
$$

is called a **linear combination** of $v_1, \dots, v_n$.

Let $W$ be the set of all linear combinations of $v_1, \dots, v_n$. Then $W$ is a **subspace** of $V$.

**Proof sketch:**
- Sum of two linear combinations is a linear combination.
- Scalar multiple of a linear combination is a linear combination.
- $O = 0v_1 + \cdots + 0v_n \in W$.

This subspace $W$ is called the subspace **generated by** $v_1, \dots, v_n$. If $W = V$, we say $v_1, \dots, v_n$ **generate** $V$.

### 1.1.7 Example 3 — Dot Product in $K^n$

For $A = (a_1, \dots, a_n)$ and $B = (b_1, \dots, b_n)$ in $K^n$, the **dot product** (or **scalar product**) is:

$$
A \cdot B = a_1 b_1 + \cdots + a_n b_n
$$

**Properties:**

| Property | Statement |
|----------|-----------|
| **SP 1.** Commutativity | $A \cdot B = B \cdot A$ |
| **SP 2.** Distributivity | $A \cdot (B + C) = A \cdot B + A \cdot C = (B + C) \cdot A$ |
| **SP 3.** Homogeneity | $(xA) \cdot B = x(A \cdot B)$ and $A \cdot (xB) = x(A \cdot B)$ |

**Additional identities:**

$$
(A + B)^2 = A^2 + 2A \cdot B + B^2, \qquad (A - B)^2 = A^2 - 2A \cdot B + B^2
$$

where $A^2 = A \cdot A$.

**Orthogonality:** $A$ and $B$ are **perpendicular** (or **orthogonal**) if $A \cdot B = 0$.

> **Note:** $A \cdot B = 0$ does not imply $A = O$ or $B = O$. Example: $A = (1, 2, 3)$, $B = (2, 1, -\frac{4}{3})$, then $A \cdot B = 0$.

Let $W$ be the set of all $B \in K^n$ such that $B \cdot A = 0$ (i.e., $B$ is perpendicular to a fixed $A$). Then $W$ is a **subspace** of $K^n$.

### 1.1.8 Example 4 — Function Spaces

Let $S$ be a set and $K$ a field. A **function** $f: S \to K$ assigns to each element of $S$ a unique element of $K$.

Let $V$ be the set of all functions from $S$ into $K$. Define:
- $(f + g)(x) = f(x) + g(x)$
- $(cf)(x) = cf(x)$ for $c \in K$

Then $V$ is a vector space over $K$. The zero element is the **zero function** $0$ (where $0(x) = 0$ for all $x \in S$).

**Subspaces of function spaces:**
- Continuous functions $\to$ subspace of all functions from $\mathbf{R}$ to $\mathbf{R}$.
- Differentiable functions $\to$ subspace of continuous functions.

**Example:** Let $f(t) = e^t$ and $g(t) = e^{2t}$. These generate a subspace of differentiable functions; $3e^t + 2e^{2t}$ and $2e^t + \pi e^{2t}$ are elements of this subspace.

### 1.1.9 Example 5 — Intersection of Subspaces

Let $U, W$ be subspaces of $V$. Then $U \cap W$ is a **subspace** of $V$.

> **Geometric intuition:** If $U, W$ are two planes through the origin in 3-space, their intersection is generally a straight line through the origin.

### 1.1.10 Example 6 — Sum of Subspaces

Let $U, W$ be subspaces of $V$. The **sum** $U + W$ is the set of all elements $u + w$ with $u \in U$ and $w \in W$. Then $U + W$ is a **subspace** of $V$, said to be generated by $U$ and $W$.
